Here's the exhaustive structured list of Kotlin keywords:

---

## Hard Keywords

These are reserved and cannot be used as identifiers.

### Class / Object System

| Keyword | Explanation |
|---------|-------------|
| `class` | Declares a class |
| `interface` | Declares an interface |
| `object` | Declares a singleton object or anonymous object |
| `typealias` | Creates an alias for an existing type |
| `typeof` | Reserved for future use (not currently usable in Kotlin/JVM) |

```kotlin
class Foo
interface Bar
object Singleton
typealias StringList = List<String>
```

### Inheritance / Delegation

| Keyword | Explanation |
|---------|-------------|
| `super` | References the superclass or superinterface member |
| `this` | References the current instance |

```kotlin
class Child : Parent() {
    override fun greet() = super.greet()
    fun self() = this
}
```

### Control Flow

| Keyword | Explanation |
|---------|-------------|
| `if` | Conditional expression/statement |
| `else` | Alternative branch of `if` or `when` |
| `when` | Multi-branch conditional (replaces `switch`) |
| `for` | Iterates over a range or iterable |
| `while` | Loop with pre-condition |
| `do` | Loop with post-condition (used with `while`) |
| `break` | Exits the nearest enclosing loop |
| `continue` | Skips to the next iteration of the nearest loop |
| `return` | Returns a value from a function |
| `throw` | Throws an exception |
| `try` | Begins an exception-handling block |

```kotlin
for (i in 1..5) {
    if (i == 3) continue
    if (i == 5) break
}

val result = try { risky() } catch (e: Exception) { null }

when (x) {
    1 -> "one"
    else -> "other"
}
```

### Variable Declaration

| Keyword | Explanation |
|---------|-------------|
| `val` | Declares a read-only (immutable reference) property or local variable |
| `var` | Declares a mutable property or local variable |

```kotlin
val pi = 3.14
var count = 0
```

### Functions

| Keyword | Explanation |
|---------|-------------|
| `fun` | Declares a function |

```kotlin
fun greet(name: String): String = "Hello, $name"
```

### Type Checks & Casts

| Keyword | Explanation |
|---------|-------------|
| `is` | Checks if a value is an instance of a type (smart cast) |
| `!is` | Negated type check |
| `as` | Unsafe cast operator |
| `as?` | Safe (nullable) cast operator; returns `null` on failure |

```kotlin
if (x is String) println(x.length)
val s = x as? String ?: "default"
```

### Null Safety

| Keyword | Explanation |
|---------|-------------|
| `null` | Represents the null reference |

```kotlin
val name: String? = null
```

### Iteration / Range Membership

| Keyword | Explanation |
|---------|-------------|
| `in` | Tests membership in a range/collection; also used in `for` loops |
| `!in` | Negated membership test |

```kotlin
if (x in 1..10) println("in range")
if (y !in listOf("a", "b")) println("not found")
```

### Package / Import

| Keyword | Explanation |
|---------|-------------|
| `package` | Declares the package for the current file |
| `import` | — (see soft keywords; note: `import` is actually a soft keyword in the spec) |

```kotlin
package com.example.app
```

### Literals

| Keyword | Explanation |
|---------|-------------|
| `true` | Boolean true literal |
| `false` | Boolean false literal |

```kotlin
val flag: Boolean = true
```

## Soft Keywords

These have special meaning only in specific contexts and can be used as identifiers elsewhere.

### Object Construction

| Keyword | Context | Explanation |
|---------|---------|-------------|
| `constructor` | Class declaration | Declares a primary or secondary constructor |
| `init` | Class body | Declares an initializer block, runs after primary constructor |

```kotlin
class Foo(val x: Int) {
    init { println("init: $x") }
    constructor(s: String) : this(s.length)
}
```

### Property Accessors

| Keyword | Context | Explanation |
|---------|---------|-------------|
| `get` | Property declaration | Declares a custom getter |
| `set` | Property declaration | Declares a custom setter |
| `field` | Inside getter/setter | References the backing field of the property |
| `value` | Inside setter | The parameter representing the new value being set |

```kotlin
var count: Int = 0
    get() = field
    set(value) { field = value.coerceAtLeast(0) }
```

### Delegation

| Keyword | Context | Explanation |
|---------|---------|-------------|
| `by` | Class/property declaration | Delegates implementation to another object |
| `delegate` | Annotation target | Used as an annotation use-site target for delegated properties |

```kotlin
val lazy: String by lazy { "computed" }
class Impl : Base by delegate
```

### Exception Handling

| Keyword | Context | Explanation |
|---------|---------|-------------|
| `catch` | After `try` block | Catches a thrown exception |
| `finally` | After `try`/`catch` | Runs regardless of whether an exception was thrown |

```kotlin
try {
    riskyOp()
} catch (e: IOException) {
    log(e)
} finally {
    cleanup()
}
```

### Imports

| Keyword | Context | Explanation |
|---------|---------|-------------|
| `import` | Top of file | Imports a class, function, or property into the current file scope |

```kotlin
import kotlin.math.sqrt
import com.example.MyClass as MC
```

### Type Constraints

| Keyword | Context | Explanation |
|---------|---------|-------------|
| `where` | Generic declaration | Specifies additional upper bound constraints on type parameters |

```kotlin
fun <T> sort(list: List<T>) where T : Comparable<T>, T : Serializable { }
```

### Annotation Targets

These are used as annotation use-site targets and are soft keywords in that context:

| Keyword | Explanation |
|---------|-------------|
| `file` | Targets the file-level annotation |
| `param` | Targets constructor parameter |
| `property` | Targets a property (not accessible via reflection on parameters) |
| `receiver` | Targets the extension receiver parameter |
| `setparam` | Targets the parameter of a property setter |

```kotlin
@file:JvmName("Utils")

@get:JvmName("getFoo")
val foo: String = "bar"

@setparam:Inject
var service: MyService = ...
```

### Multiplatform

| Keyword | Context | Explanation |
|---------|---------|-------------|
| `dynamic` | Kotlin/JS only | Opts into dynamic typing for JS interop; disables type checking |

```kotlin
val d: dynamic = js("{ x: 1 }")
d.x = 2
```

## Modifier Keywords

Used to modify declarations. Can be used as identifiers outside modifier position.

### Visibility

| Keyword | Explanation |
|---------|-------------|
| `public` | Visible everywhere (default visibility) |
| `private` | Visible only within the declaring class/file |
| `protected` | Visible in the class and its subclasses |
| `internal` | Visible within the same compilation module |

```kotlin
public class A
private val x = 1
protected fun foo() {}
internal object Bar
```

### Inheritance & Finality

| Keyword | Explanation |
|---------|-------------|
| `open` | Allows a class/member to be subclassed or overridden |
| `final` | Prevents overriding (default for classes; explicit for members) |
| `abstract` | Declares a class or member without implementation; must be overridden |
| `override` | Overrides a member from a supertype |
| `sealed` | Restricts class hierarchy to the same package/file (exhaustive `when`) |

```kotlin
open class Base { open fun foo() {} }
abstract class Shape { abstract fun area(): Double }
sealed class Result { class Ok(val v: Int) : Result() }
class Child : Base() { override fun foo() {} }
```

### Class Kinds

| Keyword | Explanation |
|---------|-------------|
| `data` | Generates `equals`, `hashCode`, `toString`, `copy`, `componentN` |
| `enum` | Declares an enumeration class |
| `annotation` | Declares an annotation class |
| `inner` | Allows a nested class to hold a reference to the outer class instance |
| `value` | Declares an inline/value class (with `@JvmInline`) |
| `companion` | Declares a companion object within a class |

```kotlin
data class Point(val x: Int, val y: Int)
enum class Direction { NORTH, SOUTH }
annotation class MyAnnotation
inner class Inner { val outer = this@Outer }
@JvmInline value class Wrapper(val v: Int)
class Foo { companion object { fun create() = Foo() } }
```

### Function Modifiers

| Keyword | Explanation |
|---------|-------------|
| `inline` | Inlines the function and its lambda parameters at call sites |
| `noinline` | Prevents a specific lambda parameter of an inline function from being inlined |
| `crossinline` | Forbids non-local returns in a lambda parameter of an inline function |
| `reified` | Allows a type parameter to be accessed at runtime (only in inline functions) |
| `tailrec` | Marks a function for tail-call optimization |
| `suspend` | Marks a function as a coroutine that can be suspended |
| `infix` | Allows a function to be called with infix notation |
| `operator` | Marks a function as an operator overload |
| `vararg` | Allows a parameter to accept a variable number of arguments |

```kotlin
inline fun <reified T> check(x: Any) = x is T
tailrec fun fib(n: Int, acc: Long = 0): Long = if (n == 0) acc else fib(n - 1, acc + n)
suspend fun fetchData(): String = withContext(Dispatchers.IO) { "data" }
infix fun Int.plus2(x: Int) = this + x
operator fun Point.plus(other: Point) = Point(x + other.x, y + other.y)
fun sum(vararg nums: Int) = nums.sum()
```

### Property Modifiers

| Keyword | Explanation |
|---------|-------------|
| `const` | Marks a `val` as a compile-time constant (only top-level or in `companion object`) |
| `lateinit` | Allows a non-null `var` to be initialized after declaration (defers null check) |

```kotlin
const val MAX = 100
lateinit var service: MyService
```

### Type Parameter Variance

| Keyword | Explanation |
|---------|-------------|
| `out` | Declaration-site covariance; type parameter can only be produced (returned) |
| `in` | Declaration-site contravariance; type parameter can only be consumed (accepted) — also a hard keyword in other contexts |

```kotlin
class Producer<out T>(val value: T)
class Consumer<in T> { fun consume(t: T) {} }
```

### Multiplatform

| Keyword | Explanation |
|---------|-------------|
| `expect` | Declares a platform-specific declaration in common code |
| `actual` | Provides the platform-specific implementation |
| `external` | Marks a declaration as implemented outside Kotlin (JS interop or JNI) |

```kotlin
// common
expect fun platformName(): String

// jvm
actual fun platformName(): String = "JVM"

external fun jsAlert(msg: String)
```

## Special Identifiers

Not reserved keywords, but have fixed conventional meaning in specific contexts.

| Identifier | Category | Context | Explanation |
|------------|----------|---------|-------------|
| `field` | Special identifier | Inside property getter/setter | References the backing field; only valid inside accessor bodies |
| `it` | Special identifier | Lambda with single parameter | Implicit name for a lambda's single parameter when not explicitly named |

```kotlin
// field
var x: Int = 0
    set(value) { field = value * 2 }  // 'field' refers to backing storage

// it
listOf(1, 2, 3).map { it * 2 }  // 'it' is the implicit lambda parameter
```

- `import` is classified as a soft keyword in the Kotlin grammar specification despite feeling like a hard keyword in practice.
