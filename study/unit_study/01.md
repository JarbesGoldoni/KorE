# Erlang Reserved Keywords & Language Constructs

## 1. Reserved Words

These are tokens the Erlang parser recognizes as keywords — you cannot use them as unquoted atom names.

---

### Control Flow

| Keyword | Explanation |
|---------|-------------|
| `if` | Evaluates a series of guard tests; executes the first branch whose guard is `true` |
| `case` | Pattern-matches an expression against a series of clauses |
| `of` | Separates the expression from the clause list in `case ... of` |
| `begin` | Opens an explicit expression sequence block; evaluates all, returns last |
| `end` | Closes `case`, `if`, `receive`, `try`, `fun`, and `begin` blocks |
| `cond` | Reserved but **not yet implemented** in standard Erlang (proposed extension) |
| `let` | Reserved but **not used** in current Erlang (legacy/future reservation) |
| `when` | Introduces a guard expression in function heads, `case`, `receive`, and `try` |

```erlang
%% if / end
classify(X) ->
    if
        X > 0 -> positive;
        X < 0 -> negative;
        true  -> zero
    end.

%% case / of / when / end
describe(X) ->
    case X of
        N when N > 100 -> big;
        N when N > 0   -> small;
        _              -> nonpositive
    end.

%% begin / end
Val = begin
    A = 1,
    B = 2,
    A + B
end.
```

---

### Exception Handling

| Keyword | Explanation |
|---------|-------------|
| `try` | Opens a block whose exceptions can be caught; paired with `catch`, `of`, `after` |
| `catch` | (1) As a standalone prefix expression: catches any exception and returns it as a value. (2) As a clause in `try`: matches specific exception classes |
| `after` | Clause in `try` that always executes regardless of success or exception (finalizer) |
| `throw` | Not a keyword — it's a BIF — but pairs with `catch`/`try` |

```erlang
%% try / catch / after / end
safe_div(A, B) ->
    try A div B of
        Result -> {ok, Result}
    catch
        error:badarith -> {error, division_by_zero}
    after
        io:format("attempt done~n")
    end.

%% standalone catch expression
Val = (catch error_prone_call()).
```

---

### Pattern Matching & Receive

| Keyword | Explanation |
|---------|-------------|
| `receive` | Blocks the current process and waits for messages matching one of the patterns |
| `after` | Timeout clause inside `receive`; fires if no message matches within N milliseconds |

```erlang
wait_for_reply() ->
    receive
        {reply, Msg} -> Msg;
        stop         -> done
    after 5000 ->
        timeout
    end.
```

---

### Anonymous Functions

| Keyword | Explanation |
|---------|-------------|
| `fun` | Creates an anonymous function (lambda) or captures a named function reference |

```erlang
Square = fun(X) -> X * X end.
Ref    = fun lists:reverse/1.         % function capture
Ref2   = fun module:func/arity.
```

---

### Boolean & Logical Operators

| Keyword | Explanation |
|---------|-------------|
| `and` | Strict boolean AND — evaluates **both** operands |
| `or` | Strict boolean OR — evaluates **both** operands |
| `not` | Boolean NOT |
| `xor` | Boolean exclusive OR |
| `andalso` | Short-circuit AND — right side not evaluated if left is `false` |
| `orelse` | Short-circuit OR — right side not evaluated if left is `true` |

```erlang
A = true and false.     %% false  (both sides evaluated)
B = true orelse error.  %% true   (right side never evaluated)
C = not true.           %% false
D = true xor true.      %% false
```

---

### Bitwise Operators

| Keyword | Explanation |
|---------|-------------|
| `band` | Bitwise AND |
| `bor` | Bitwise OR |
| `bxor` | Bitwise XOR |
| `bnot` | Bitwise NOT (ones' complement) |
| `bsl` | Bit shift left |
| `bsr` | Bit shift right |

```erlang
X = 2#1010 band 2#1100.   %% 2#1000  (8)
Y = 2#1010 bor  2#0101.   %% 2#1111  (15)
Z = 2#1010 bxor 2#1100.   %% 2#0110  (6)
W = bnot 0.               %% -1
S = 1 bsl 4.              %% 16
R = 16 bsr 2.             %% 4
```

---

### Arithmetic Operators

| Keyword | Explanation |
|---------|-------------|
| `div` | Integer division (truncates toward zero) |
| `rem` | Integer remainder (sign follows dividend) |

```erlang
Q = 17 div 5.   %% 3
R = 17 rem 5.   %% 2
```

## 2. Module & File Directives

Directives are file-level attributes starting with `-`. They are processed at compile time.

---

### Module Identity & Exports

| Directive | Explanation |
|-----------|-------------|
| `-module(Name)` | Declares the module name; must match the filename |
| `-export([F/A, ...])` | Makes listed functions callable from other modules |
| `-export_type([T/A, ...])` | Exports type definitions for use in other modules' `-spec`s |
| `-import(Mod, [F/A, ...])` | Imports functions so they can be called without the `Mod:` prefix |

```erlang
-module(geometry).
-export([area/1]).
-export_type([shape/0]).
-import(math, [sqrt/1]).

-type shape() :: {circle, number()} | {rect, number(), number()}.

area({circle, R}) -> math:pi() * R * R;
area({rect, W, H}) -> W * H.
```

---

### Macros & Includes

| Directive | Explanation |
|-----------|-------------|
| `-define(Name, Value)` | Defines a macro; referenced as `?Name` |
| `-define(Name(Args), Body)` | Defines a parameterized macro |
| `-include(File)` | Includes a `.hrl` header file (path relative to source) |
| `-include_lib(File)` | Includes a header file relative to an OTP application root |
| `-undef(Name)` | Undefines a previously defined macro |
| `-ifdef(Name)` | Conditional compilation: true if macro is defined |
| `-ifndef(Name)` | Conditional compilation: true if macro is **not** defined |
| `-else` | Else branch for `-ifdef`/`-ifndef` |
| `-endif` | Closes an `-ifdef`/`-ifndef` block |

```erlang
-define(MAX_SIZE, 1024).
-define(DBG(Msg), io:format("DEBUG: ~p~n", [Msg])).
-include("records.hrl").
-include_lib("kernel/include/logger.hrl").

-ifdef(debug).
log(X) -> ?DBG(X).
-else.
log(_) -> ok.
-endif.

foo() -> ?MAX_SIZE.
```

---

### Records

| Directive | Explanation |
|-----------|-------------|
| `-record(Name, {Fields})` | Defines a named record (syntactic sugar over tuples) |

```erlang
-record(person, {name, age = 0, email}).

greet(#person{name = N}) ->
    io:format("Hello ~s~n", [N]).

make() ->
    #person{name = "Alice", age = 30}.
```

---

### Type System

| Directive | Explanation |
|-----------|-------------|
| `-type Name(Params) :: TypeExpr` | Defines a public named type |
| `-opaque Name(Params) :: TypeExpr` | Defines a type whose internal structure is hidden outside the module |
| `-spec Name(ArgTypes) -> RetType` | Specifies the type signature of a function |
| `-callback Name(ArgTypes) -> RetType` | Declares a callback that behaviour implementations must provide |

```erlang
-type user_id() :: pos_integer().
-opaque token()  :: binary().

-spec create_token(user_id()) -> token().
create_token(Id) -> integer_to_binary(Id).

%% In a behaviour module:
-callback init(Args :: term()) -> {ok, State :: term()} | {error, Reason :: term()}.
```

---

### Behaviours

| Directive | Explanation |
|-----------|-------------|
| `-behaviour(Name)` | Declares that this module implements the named behaviour (e.g., `gen_server`) |
| `-behavior(Name)` | American spelling alias — identical effect |

```erlang
-module(my_server).
-behaviour(gen_server).

init([]) -> {ok, #{}}.
handle_call(_Req, _From, State) -> {reply, ok, State}.
handle_cast(_Msg, State) -> {noreply, State}.
handle_info(_Info, State) -> {noreply, State}.
terminate(_Reason, _State) -> ok.
code_change(_OldVsn, State, _Extra) -> {ok, State}.
```

---

### Compilation & Runtime Attributes

| Directive | Explanation |
|-----------|-------------|
| `-compile(Options)` | Passes compiler options (e.g., `export_all`, `nowarn_unused_vars`) |
| `-vsn(Value)` | Embeds a version string/term in the module's attribute chunk |
| `-on_load({Fun, 0})` | Names a zero-arity function to run when the module is first loaded |
| `-nifs([F/A, ...])` | Declares which functions will be replaced by NIFs at runtime |
| `-file(Name, Line)` | Overrides the filename/line reported in error messages (used by preprocessors) |
| `-deprecated([{F,A,Desc}, ...])` | Marks functions as deprecated for Dialyzer/compiler warnings |
| `-dialyzer(Options)` | Passes hints or suppressions directly to Dialyzer |
| `-feature(Flag, enable|disable)` | Enables/disables experimental language features (OTP 25+) |

```erlang
-compile([export_all, nowarn_export_all]).
-vsn("1.0.0").
-on_load(init_nif/0).
-nifs([fast_hash/1]).

init_nif() ->
    erlang:load_nif("./my_nif", 0).
```

## 3. Guards

Guards are restricted boolean expressions used in `when` clauses. Only a whitelisted set of expressions is allowed (no side effects).

### Guard Types (built-in type tests)

| Guard | Explanation |
|-------|-------------|
| `is_atom(X)` | True if X is an atom |
| `is_binary(X)` | True if X is a binary |
| `is_bitstring(X)` | True if X is a bitstring (not necessarily byte-aligned) |
| `is_boolean(X)` | True if X is `true` or `false` |
| `is_float(X)` | True if X is a float |
| `is_function(X)` | True if X is a fun |
| `is_function(X, N)` | True if X is a fun with arity N |
| `is_integer(X)` | True if X is an integer |
| `is_list(X)` | True if X is a proper or improper list |
| `is_map(X)` | True if X is a map |
| `is_map_key(K, M)` | True if key K exists in map M |
| `is_number(X)` | True if X is an integer or float |
| `is_pid(X)` | True if X is a process identifier |
| `is_port(X)` | True if X is a port identifier |
| `is_record(X, Tag)` | True if X is a record with tag Tag |
| `is_record(X, Tag, N)` | True if X is a record with tag Tag and N fields |
| `is_reference(X)` | True if X is a reference |
| `is_tuple(X)` | True if X is a tuple |

```erlang
safe_len(X) when is_list(X) -> length(X);
safe_len(X) when is_map(X)  -> map_size(X);
safe_len(_)                  -> undefined.
```

### Guard BIFs (allowed in guards)

| Guard BIF | Explanation |
|-----------|-------------|
| `abs(N)` | Absolute value |
| `bit_size(B)` | Number of bits in a bitstring |
| `byte_size(B)` | Number of bytes (rounds up) in a bitstring |
| `element(N, T)` | Nth element of tuple T |
| `float(N)` | Converts N to float |
| `hd(L)` | Head of list |
| `length(L)` | Length of list |
| `map_size(M)` | Number of keys in map |
| `max(A, B)` | Maximum of two terms (OTP 26+, also allowed in guards) |
| `min(A, B)` | Minimum of two terms (OTP 26+) |
| `node()` | Current node name |
| `node(X)` | Node of a pid/port/reference |
| `round(N)` | Rounds float to nearest integer |
| `self()` | Current process PID |
| `size(X)` | Size of tuple or binary (legacy; prefer `tuple_size`/`byte_size`) |
| `tl(L)` | Tail of list |
| `trunc(N)` | Truncates float to integer |
| `tuple_size(T)` | Number of elements in tuple |

```erlang
first_positive([H|_]) when H > 0 -> H;
first_positive([_|T])             -> first_positive(T).

bounded(X) when X >= 0, X =< 255 -> byte;  %% comma = AND in guards
bounded(_)                         -> out_of_range.
```

### Guard Separators

| Syntax | Explanation |
|--------|-------------|
| `,` (comma) | AND within a guard sequence (both must be true) |
| `;` (semicolon) | OR between guard alternatives (either can be true) |

## 4. Bit Syntax Constructs

Erlang's bit syntax allows precise binary pattern matching and construction.

### Syntax Overview

```
<<Segment, ...>>
Segment = Value | Value:Size | Value/TypeSpec | Value:Size/TypeSpec
```

### Type Specifiers

| Specifier | Explanation |
|-----------|-------------|
| `integer` | Segment is an integer (default) |
| `float` | Segment is a floating-point number |
| `binary` | Segment is a binary (byte-aligned) |
| `bytes` | Alias for `binary` |
| `bitstring` | Segment is a bitstring (not necessarily byte-aligned) |
| `bits` | Alias for `bitstring` |
| `utf8` | Segment is a UTF-8 encoded codepoint |
| `utf16` | Segment is a UTF-16 encoded codepoint |
| `utf32` | Segment is a UTF-32 encoded codepoint |

### Endianness Specifiers

| Specifier | Explanation |
|-----------|-------------|
| `big` | Big-endian byte order (default) |
| `little` | Little-endian byte order |
| `native` | Host CPU's native byte order |

### Signedness Specifiers

| Specifier | Explanation |
|-----------|-------------|
| `unsigned` | Unsigned integer (default) |
| `signed` | Signed integer (two's complement) |

### Unit Specifier

| Specifier | Explanation |
|-----------|-------------|
| `unit:N` | Size is measured in N-bit units (1–256); default is 1 for bitstring, 8 for binary |

### The `-` separator

Multiple specifiers are separated by `-` within a segment.

```erlang
%% Construction
Pixel = <<R:8, G:8, B:8>>.
Float = <<3.14:64/float-big>>.
UTF   = <<$é/utf8>>.

%% Matching
<<Version:4, IHL:4, _:8, TotalLen:16>> = IPHeader.

parse_rgb(<<R:8, G:8, B:8>>) -> {R, G, B}.

%% Variable-length
<<Len:16, Data:Len/binary, Rest/binary>> = Packet.

%% Signed little-endian
<<Val:16/signed-little>> = <<255, 255>>.   %% Val = -1
```

## 5. List Comprehension Constructs

### Syntax

```
[Expr || Qualifier, ...]
```

### Qualifiers

| Construct | Explanation |
|-----------|-------------|
| `<-` (generator) | `Pattern <- List` — iterates over a list, binding each element to Pattern |
| `<=` (binary generator) | `Pattern <= Binary` — iterates over a binary, binding bitstring segments |
| `<-` with map (OTP 26+) | `K := V <- Map` — iterates over key-value pairs of a map |
| Filter expression | Any boolean expression in the qualifier list; excludes elements where false |

### Comprehension Variants

| Form | Explanation |
|------|-------------|
| `[... \|\| ...]` | List comprehension — produces a list |
| `<< ... \|\| ... >>` | Binary comprehension — produces a binary |
| `#{... \|\| ...}` | Map comprehension (OTP 26+) — produces a map |

```erlang
%% List comprehension
Squares = [X*X || X <- lists:seq(1,5)].
%% [1,4,9,16,25]

%% With filter
Evens = [X || X <- lists:seq(1,10), X rem 2 =:= 0].
%% [2,4,6,8,10]

%% Multiple generators (cartesian product)
Pairs = [{X,Y} || X <- [1,2], Y <- [a,b]].
%% [{1,a},{1,b},{2,a},{2,b}]

%% Pattern filter (non-matching patterns are silently skipped)
Values = [V || {ok, V} <- Results].

%% Binary comprehension
Doubled = <<(X*2):8 || <<X:8>> <= <<1,2,3>>>.
%% <<2,4,6>>

%% Map comprehension (OTP 26+)
Inverted = #{V => K || K := V <- #{a => 1, b => 2}}.
%% #{1 => a, 2 => b}
```

## 6. Try / Catch / After Constructs (detailed)

### Full Syntax

```erlang
try Expr [of
    Pattern [when Guard] -> Body;
    ...
catch
    [Class:]Pattern [when Guard] -> Body;
    ...
after
    AfterBody
end
```

### Exception Classes

| Class | Explanation |
|-------|-------------|
| `error` | Runtime errors raised by `erlang:error/1,2,3` or the VM (e.g., `badmatch`, `badarith`) |
| `exit` | Process exit signals raised by `erlang:exit/1` |
| `throw` | Controlled non-local jumps raised by `erlang:throw/1` |
| `_` (catch-all class) | Matches any class when used as `_:Pattern` |

```erlang
result(Expr) ->
    try Expr of
        {ok, V}    -> {success, V};
        {error, E} -> {failure, E}
    catch
        throw:Val          -> {thrown, Val};
        error:badarg       -> {bad_argument};
        error:Reason       -> {runtime_error, Reason};
        exit:Reason        -> {process_exit, Reason};
        _Class:_Reason     -> unknown
    after
        cleanup()
    end.
```

### Stack Trace Capture

```erlang
try risky()
catch
    Class:Reason:Stacktrace ->
        io:format("~p:~p~n~p~n", [Class, Reason, Stacktrace])
end.
```

The three-part `Class:Reason:Stacktrace` syntax (OTP 21+) captures the full stack trace without `erlang:get_stacktrace/0` (which is deprecated).

## 7. Special Syntax Forms (not keywords, but core language syntax)

| Form | Category | Explanation |
|------|----------|-------------|
| `_` | Pattern matching | Wildcard — matches anything, binds nothing |
| `_Var` | Pattern matching | Named wildcard — matches anything; name signals intent but isn't bound for use |
| `=` | Pattern matching | Match operator — unifies left and right; also assignment on first bind |
| `=:=` | Comparison | Strict equality (no type coercion) |
| `=/=` | Comparison | Strict inequality |
| `==` | Comparison | Equality with numeric coercion (`1 == 1.0` is true) |
| `/=` | Comparison | Inequality with numeric coercion |
| `!` | Concurrency | Send a message: `Pid ! Message` |
| `#{}` | Maps | Empty map literal |
| `#{K => V}` | Maps | Map construction with `=>` (any key) |
| `#{K := V}` | Maps | Map update/match with `:=` (key must exist) |
| `#rec{}` | Records | Record construction/match syntax |
| `#rec.field` | Records | Extracts field index (integer) for use with `element/2` |
| `...` (in `-spec`) | Type system | Represents a non-empty list tail or varargs in type specs |
| `|` | Types / patterns | Union type separator in `-type`; cons separator in list patterns |
| `?MODULE` | Macros | Predefined macro expanding to the current module name atom |
| `?MODULE_STRING` | Macros | Predefined macro expanding to the module name as a string |
| `?LINE` | Macros | Predefined macro expanding to the current source line number |
| `?FILE` | Macros | Predefined macro expanding to the current source filename string |
| `?FUNCTION_NAME` | Macros | Current function name atom (OTP 19+) |
| `?FUNCTION_ARITY` | Macros | Current function arity integer (OTP 19+) |
| `?OTP_RELEASE` | Macros | OTP release number integer (OTP 21+) |

```erlang
%% Wildcard patterns
f({ok, _}) -> ok;
f({error, _Reason}) -> error.   %% _Reason documents intent

%% Match operator dual use
{X, X} = {42, 42}.    %% pattern: both elements must be equal
Y = compute().         %% bind Y

%% Message send
Pid ! {self(), hello}.

%% Map construction vs update
M1 = #{a => 1}.
M2 = M1#{a := 2}.     %% update existing key
M3 = M1#{b => 3}.     %% add new key (=> works for both)

%% Predefined macros
-spec ?MODULE:foo() -> ok.
io:format("line ~p in ~s~n", [?LINE, ?FILE]).
```

## 8. Process & Concurrency Primitives (BIFs used as language primitives)

These are not keywords but are so fundamental to Erlang semantics they belong in any exhaustive reference:

| BIF | Explanation |
|-----|-------------|
| `spawn(Fun)` | Creates a new process running Fun; returns its PID |
| `spawn(M, F, A)` | Spawns M:F(A) in a new process |
| `spawn_link(Fun)` | Spawns and links to the new process (bidirectional failure propagation) |
| `spawn_monitor(Fun)` | Spawns and monitors the new process; returns `{Pid, Ref}` |
| `self()` | Returns the PID of the calling process |
| `exit(Reason)` | Terminates the calling process with Reason |
| `exit(Pid, Reason)` | Sends an exit signal to Pid |
| `link(Pid)` | Creates a bidirectional link |
| `unlink(Pid)` | Removes a link |
| `monitor(process, Pid)` | Monitors a process; delivers `{'DOWN', Ref, ...}` on termination |
| `demonitor(Ref)` | Removes a monitor |
| `process_flag(trap_exit, true)` | Converts exit signals into `{'EXIT', Pid, Reason}` messages |
| `register(Name, Pid)` | Registers a PID under a global atom name |
| `whereis(Name)` | Looks up a registered name; returns PID or `undefined` |

```erlang
%% Spawn + send/receive
Pid = spawn(fun() ->
    receive
        {from, Caller, Msg} -> Caller ! {reply, Msg}
    end
end),
Pid ! {from, self(), hello},
receive
    {reply, R} -> io:format("got: ~p~n", [R])
end.

%% Monitored spawn
{Pid, Ref} = spawn_monitor(fun risky_work/0),
receive
    {'DOWN', Ref, process, Pid, Reason} ->
        io:format("died: ~p~n", [Reason])
end.
```
