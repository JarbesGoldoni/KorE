# 05 - Recursion

KorE has no `while` loops. Iteration is done via recursion or collection
methods like `fold`. This example demonstrates:

- Tail-recursive factorial with an accumulator parameter
- Default parameter values for the accumulator
- Non-tail recursive fibonacci (for clarity, not performance)
- Recursive side-effecting countdown

## Run

```sh
kore run
```

## Expected output

```
5! = 120
fib(10) = 55
Countdown:
5
4
3
2
1
```
