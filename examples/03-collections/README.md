# 03 - Collections

Demonstrates lists and maps with functional method chains:

- `listOf` and `mapOf` constructors
- `map`, `filter`, `fold` for transformation and accumulation
- `plus` for appending (immutable)
- `size` property
- Map operations: `get`, `put`, `containsKey`
- Elvis operator `?:` for default values

## Run

```sh
kore run
```

## Expected output

```
Sum of doubled evens: 30
Extended size: 6
Alice: 95
Has Charlie: true
```
