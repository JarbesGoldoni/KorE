# 04 - Null Safety

Demonstrates KorE's nullable type system:

- `T?` nullable type annotations
- `?.` safe navigation operator (short-circuits on null)
- `?:` elvis operator for default values
- `!!` non-null assertion (raises on null)
- `null` literal

## Run

```sh
kore run
```

## Expected output

```
Diego: Loves KorE
Ghost: No bio
Forced: Loves KorE
```
