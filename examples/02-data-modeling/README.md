# 02 - Data Modeling

Demonstrates KorE's algebraic data types and pattern matching:

- `data` records with default field values
- `sealed` sum types (tagged unions)
- `when` expressions with exhaustive pattern matching
- Destructuring with `is Variant(val field)`
- `copy` for immutable record updates
- Built-in `Ok`/`Error` result constructors

## Run

```sh
kore run
```

## Expected output

```
Diego is 30, next year 31
Active since 2024
Got: success
```
