# KorE

**KorE** is a Kotlin-flavoured programming language that targets the Erlang Virtual Machine (BEAM) by transpiling to idiomatic Elixir source code.

It brings JVM developers into the Erlang/OTP ecosystem with familiar Kotlin syntax—including static type annotations, null-safety operators, data records, sealed sum types, pattern matching, and actors—while emitting readable, production-ready Elixir and GenServers underneath.

---

## Key Features

- **Familiar Kotlin Syntax**: `fun`, `val` / `var`, `if` expressions, `when` pattern matching, and trailing lambdas.
- **Immutable by Default (`val` vs `var`)**:
  - `val` creates immutable bindings (`val x = 1`).
  - `var` allows local rebinding (`var count = 0`), which the compiler automatically threads through `if` and `when` statements (SSA-style var-threading). Rebinding `var` inside lambdas is safely rejected at compile-time.
- **Data Records & Sealed Types**:
  - `data User(val name: String, val age: Int = 0)` compiles to Elixir structs with `@enforce_keys`, type specifications (`@type t`), and default constructors.
  - `sealed Shape { data Circle(val r: Double) data Rect(val w: Double, val h: Double) }` defines sum types with compile-time exhaustiveness checks on `when` expressions.
- **Seamless `Result` & Erlang/Elixir Interop**:
  - `Result<T, E>` maps natively to `{:ok, value}` and `{:error, reason}` tuples for zero-overhead interop with Elixir and Erlang libraries.
  - Call Elixir modules directly via `import elixir.Module.Submodule`.
- **Null Safety**:
  - Nullable types (`T?`), safe navigation (`?.`), elvis default operator (`?:`), and forced unwrap (`!!`).
- **Concurrency & Actor Model**:
  - Process primitives: `spawn { ... }`, `pid.send(msg)`, and `receive { is String -> ... }`.
  - High-level `actor` constructs transpile directly into OTP `GenServer` implementations (`cast` for `Unit` methods, `call` for synchronous return values).
- **Compile-time Prelude**:
  - Method-call syntax (`list.map { ... }`, `list.fold(0) { a, b -> ... }`, `str.uppercase()`, `map.get(k)`) maps at compile-time directly to Elixir stdlib (`Enum`, `String`, `Map`, `List`) with zero runtime overhead.

## Quick Example

`lib/bank.kore`:

```kotlin
module Bank {
    data Account(val owner: String, val balance: Int = 0)

    sealed TxResult {
        data Approved(val newBalance: Int)
        data Denied(val reason: String)
    }

    fun withdraw(acc: Account, amount: Int): TxResult =
        if (amount <= acc.balance) Approved(acc.balance - amount)
        else Denied("insufficient funds")

    fun report(acc: Account, amount: Int): String {
        var msg = "pending"
        when (withdraw(acc, amount)) {
            is Approved(val b) -> { msg = "ok, new balance $b" }
            is Denied(val r) -> { msg = "denied: $r" }
        }
        return msg
    }
}
```

Transpiles to idiomatic Elixir in `_build/kore_gen/lib/bank.ex`:

```elixir
# Generated by KorE v0.1 — do not edit. Source: lib/bank.kore

defmodule Kore.Bank.Account do
  @enforce_keys [:owner]
  defstruct [owner: nil, balance: 0]
  @type t :: %__MODULE__{owner: String.t(), balance: integer()}
  def new(owner, balance \\ 0), do: %__MODULE__{owner: owner, balance: balance}
end

defmodule Kore.Bank.TxResult do
  @type t :: Kore.Bank.TxResult.Approved.t() | Kore.Bank.TxResult.Denied.t()
end

defmodule Kore.Bank.TxResult.Approved do
  @enforce_keys [:new_balance]
  defstruct [new_balance: nil]
  @type t :: %__MODULE__{new_balance: integer()}
  def new(new_balance), do: %__MODULE__{new_balance: new_balance}
end

defmodule Kore.Bank.TxResult.Denied do
  @enforce_keys [:reason]
  defstruct [reason: nil]
  @type t :: %__MODULE__{reason: String.t()}
  def new(reason), do: %__MODULE__{reason: reason}
end

defmodule Kore.Bank do
  @spec withdraw(Kore.Bank.Account.t(), integer()) :: Kore.Bank.TxResult.t()
  def withdraw(acc, amount) when is_struct(acc, Kore.Bank.Account) and is_integer(amount) do
    if amount <= acc.balance do
      Kore.Bank.TxResult.Approved.new(acc.balance - amount)
    else
      Kore.Bank.TxResult.Denied.new("insufficient funds")
    end
  end

  @spec report(Kore.Bank.Account.t(), integer()) :: String.t()
  def report(acc, amount) when is_struct(acc, Kore.Bank.Account) and is_integer(amount) do
    msg = "pending"
    msg = case withdraw(acc, amount) do
      %Kore.Bank.TxResult.Approved{new_balance: b} ->
        msg = "ok, new balance #{b}"
        msg
      %Kore.Bank.TxResult.Denied{reason: r} ->
        msg = "denied: #{r}"
        msg
    end
    msg
  end
end
```

## Getting Started

### Prerequisites

- **Elixir** (`~> 1.14` or later)
- **Erlang/OTP**

### Building the Compiler CLI

Clone the repository and build the standalone `kore` escript:

```bash
git clone https://github.com/JarbesGoldoni/KorE.git
cd KorE
mix deps.get
mix compile
mix escript.build
```

This generates the `kore` binary executable in the repository root.

---

## CLI Usage

### 1. Scaffold a New Project

```bash
./kore new myapp
cd myapp
```

This creates a new project directory with the following layout:
```text
myapp/
├── kore.exs            # Project configuration (name, version)
├── lib/
│   └── main.kore       # Entry module Main
└── .gitignore
```

### 2. Build the Project

```bash
kore build
```

Compiles all `.kore` files in `lib/` to Elixir source code inside `_build/kore_gen/`, and invokes `mix compile` to generate `.beam` bytecode.

### 3. Run the Project

```bash
kore run
```

Builds the project and executes `Kore.Main.main()`. You can also specify a custom module to run:

```bash
kore run Kore.UserService
```

## Language Reference

### Types & Elixir Mapping

| KorE Type | Elixir Typespec | Runtime Guard / Representation |
|---|---|---|
| `Int` | `integer()` | `is_integer/1` |
| `Double` | `float()` | `is_float/1` |
| `Boolean` | `boolean()` | `is_boolean/1` |
| `String` | `String.t()` | `is_binary/1` |
| `Atom` | `atom()` | `is_atom/1` |
| `Unit` | `:ok` | Function returns `:ok` |
| `Any` | `term()` | Passthrough |
| `List<T>` | `[t()]` | `is_list/1` |
| `Map<K, V>` | `%{optional(k) => v}` | `is_map/1` |
| `Pair<A, B>` | `{a(), b()}` | `is_tuple/1` |
| `T?` | `t() \| nil` | Guard on `t` or `nil` |
| `Result<T, E>` | `{:ok, t()} \| {:error, e()}` | Tagged tuples `{:ok, x}` / `{:error, e}` |
| `data Foo(...)` | `%Foo{}` struct | `is_struct(x, Foo)` |
| `(A) -> B` | `(a() -> b())` | `is_function/2` |
| `Pid` | `pid()` | `is_pid/1` |

### Actors (GenServer)

```kotlin
actor Counter(var count: Int = 0) {
    fun increment() { count = count + 1 } // Unit return -> GenServer.cast (async)
    fun add(n: Int) { count = count + n } // Unit return -> GenServer.cast (async)
    fun get(): Int = count                // Int return -> GenServer.call (sync)
}
```

Usage:

```kotlin
val c = Counter.start(10)
c.increment()
c.add(5)
val current = c.get() // 16
```

## Compiler Architecture

```text
 .kore files
     │
     ▼
 ┌───────────┐   ┌───────────┐   ┌──────────────────┐   ┌───────────────┐
 │  Lexer    │──▶│  Parser   │──▶│ Semantic passes  │──▶│ Elixir codegen│
 └───────────┘   └───────────┘   └──────────────────┘   └───────────────┘
   tokens          KorE AST        resolved/rewritten       .ex files in
                                   AST                      _build/kore_gen/
                                                                 │
                                                                 ▼
                                                          mix compile → .beam
```

1. **Lexer** (`lib/kore/lexer.ex`): Scanner supporting string interpolation, keywords, operators, and comments.
2. **Parser** (`lib/kore/parser.ex`): Recursive descent with Pratt expression parser.
3. **Semantic Passes**:
   - **Scopes** (`lib/kore/semantics/scopes.ex`): Name resolution, module/file name validation, early return checks.
   - **Closures** (`lib/kore/semantics/closures.ex`): Prevents `var` mutation inside closures.
   - **Var Threading** (`lib/kore/semantics/var_threading.ex`): Rebinds `var`s across `if`/`when` statements via SSA tuple destructuring.
   - **Exhaustiveness** (`lib/kore/semantics/exhaustive.ex`): Validates sealed sum-type `when` branches.
   - **Typecheck** (`lib/kore/typecheck.ex`): Minimal local checks for literals, arity, and constructors.
4. **Elixir Codegen** (`lib/kore/codegen/elixir.ex`): Deterministic Elixir source code generator with `@spec` and guard emission.

## Testing

Run the full test suite (unit, end-to-end, golden, runtime execution, and error diagnostics):

```bash
mix test
```

### Golden Tests

Golden tests compare `.kore` compilation output against expected `.ex` files in `test/golden/cases/`.

To regenerate golden files after intentional compiler changes:

```bash
KORE_UPDATE_GOLDEN=1 mix test test/golden_test.exs
```
